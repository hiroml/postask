# 回答の反映

## 手順

1. `docs/questions.md` を読み、「回答待ち」のうち `回答:` が書かれている項目を集める。
2. 回答があいまいな項目、回答どうしが矛盾する項目は反映せず、ユーザーに聞き返す。
3. 各回答を関連文書に反映する。
   - 仕様書: 該当する要件・データ定義・スコープ外を直す。「未決事項」のチェックを付け、`変更履歴` に1行足す
   - 設計に大きく影響する決定（技術選定、データ構造、外部サービス）: `docs/decisions/` に ADR を追加または更新する
   - 前提が変わる場合: `docs/project/` も更新する
4. 反映した項目を「回答待ち」から消し、「決定済み」の表に1行ずつ追加する（ID・内容・決定・日付・反映先）。
5. 反映で新しい疑問が出たら、次の番号で「回答待ち」に追加する。
6. 変更したファイルを commit する（例: `docs(001): Q-004〜Q-009 の回答を反映`）。

## 完了時の報告

- 反映した項目と、変更したファイル
- まだ回答待ちの項目（特に 🔴）
- 仕様書の未決事項がすべて解消した場合は、「承認（`status: approved`）できる状態です」と伝える

## 禁止事項

- 回答の書かれていない項目を、推奨案で勝手に決めない
- 仕様書の `status` を `approved` にしない（人のみが行う）
