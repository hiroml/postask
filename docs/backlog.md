# バックログ

残課題・issue・機能追加・改善・バグ報告をまとめて管理する一覧です。人も AI も書き込みます。
**3件ずつのバッチ**で進めます。

- 決定が必要なこと → [判断待ちボード](questions.md)
- 「何をやるか・どの順でやるか」 → このファイル

## 使い方

**人**
- 思い付いたことは「受付箱」に1行で書くだけでOK（形式は気にしない）
- 次にやる3件を選ぶ（または AI の提案から選ぶ）→「今回のバッチ」に入る

**AI**
- 受付箱の内容を整理して「一覧」に登録し、受付箱から消す（`/backlog`）
- 作業中に見つけた問題・改善案は、起票者 `AI` として一覧に追加する
- 状態が変わったら更新して commit する
- バッチの3件を選ぶときは提案まで。決めるのは人

### 種別

| 種別 | 意味 |
| --- | --- |
| 機能 | 新しくできるようになること |
| 改善 | 既存機能の使い勝手・品質の向上 |
| バグ | 期待どおりに動かないこと |
| 技術 | 利用者からは見えない内部の課題（構成・依存・ビルドなど） |

### 状態

| 状態 | 意味 |
| --- | --- |
| 未着手 | 登録済み。まだ手を付けていない |
| 仕様化 | 仕様書を作成中・承認待ち |
| 実装中 | 実装ブランチで作業中 |
| 確認待ち | 人のレビュー（ゲート2）待ち |
| 完了 | main にマージ済み |
| 保留 | いったん止めている（理由を備考に書く） |
| 見送り | やらないと決めた（理由を備考に書く） |

**優先度**: 高 / 中 / 低　**起票**: 人 / AI
