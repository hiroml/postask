# 004: 開発用 DB の分離

## 背景・目的

`cargo tauri dev` はコードの変更を検知してアプリを自動で再起動する。2026-09-26、AI が実装ブランチで作業している間に、
ユーザーが普段使っているアプリの DB（`x-clone.sqlite`）が作業中のコードで新しい版に更新された（データは無事。[review 002](../reviews/002-complete-task.md)）。

今後もマイグレーションは増えていく（B-017 話題、B-023 期限など）。作業中のコードが普段使いのデータに触れないよう、
**開発用のビルドでは別の DB ファイルを使う**。

## ユーザーストーリー

- ユーザーとして、AI が開発中でも、普段使っているポストやタスクが壊れる心配をしたくない。
- ユーザーとして、今開いているアプリが開発版か普段使いかを、見て分かるようにしたい。

## 要件

### 機能要件

- [ ] FR-1: 開発用ビルド（`cargo tauri dev`、デバッグビルド）は `x-clone-dev.sqlite` を使う。リリースビルド（`cargo tauri build` で作った exe）は今までどおり `x-clone.sqlite` を使う。どちらも同じアプリデータ用フォルダに置く。
- [ ] FR-2: 開発用 DB が無いときだけ、普段使いの `x-clone.sqlite` をコピーして始める（Q-023）。コピー元は読むだけで変更しない。普段使いの DB も無い（初めての起動）ときは空で始める。やり直したいときは `x-clone-dev.sqlite` を消せば、次の起動でまたコピーされる。
- [ ] FR-3: 開発用ビルドでは、ウィンドウのタイトルを「x-clone（開発版）」にし、画面の左上（ナビゲーターが入るまではヘッダー）に「開発版」の小さな印を出す。
- [ ] FR-4: 起動時に、使っている DB ファイルのパスをターミナルに表示する（「DB: …\x-clone-dev.sqlite」）。
- [ ] FR-5: 環境変数 `X_CLONE_DB` にファイルのパスを入れると、そのファイルを使う（テストや、特定のデータで試したいとき用）。`.env` にも書ける。

### 非機能要件

- NFR-1: リリースビルドの動きは変えない（普段使いの DB の場所・名前はそのまま）。
- NFR-2: 開発版と普段使いのアプリを同時に起動しても、互いの DB に触れない。

## 受け入れ条件

- [ ] AC-1: `cargo tauri dev` で起動すると、ターミナルに `x-clone-dev.sqlite` のパスが表示され、タイトルと画面に「開発版」が出る。
- [ ] AC-2: 開発版でポストしても、普段使いの `x-clone.sqlite` の更新日時が変わらない。
- [ ] AC-3: `x-clone-dev.sqlite` が無い状態で開発版を起動すると、普段使いのポスト・タスクが入った状態で始まる。普段使いの DB の更新日時は変わらない。
- [ ] AC-4: `X_CLONE_DB` を設定すると、そのファイルが使われる（単体テスト＋手動確認）。
- [ ] AC-5: どの DB を使うかを決める処理の単体テストが通る（開発版・リリース版・環境変数あり）。

## 画面・UI

```
┌─────────────────────────────────────┐
│ ホーム                   [開発版]    │  ← 開発版のときだけ、黄色系の小さな印
```

## データ・API

- DB ファイル名を決める処理を `db.rs`（または `config.rs`）に置く。
  - 優先順位: `X_CLONE_DB`（環境変数） > デバッグビルドなら `x-clone-dev.sqlite` > `x-clone.sqlite`
- 開発版かどうかをフロントに伝えるため、`app_info` コマンドを追加する（`{ dev: bool, db_path: String }`）。
- 初回コピー（Q-023）: 開発用 DB が無いときだけ、`x-clone.sqlite` をコピーしてから開く。コピー元は読むだけで変更しない。

## スコープ外

- DB のバックアップ・書き出し機能（必要ならバックログに起票）
- 開発用 DB の中身を画面から消す・作り直す機能

## 補足（AI の作業ルール）

この仕様の実装後は、ユーザーの `cargo tauri dev` が動いていても、AI の作業で普段使いの DB が変わることは無くなる。
AI が開発版で動作確認するときも `x-clone-dev.sqlite` を使う。
