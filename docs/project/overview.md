# プロジェクト概要

> 人が方針を記入するファイルです。AI はここを前提として仕様や実装を考えます。

## コンセプト

**「つぶやくだけで、タスクが整理される」**

X（旧Twitter）のように気軽に投稿するだけで、AI とアルゴリズムが投稿を読み取り、
課題・思い付き・調査などに分類してタスク化・可視化する、新しいタスク管理ツール。

## 目的

- タスク登録の手間をなくし、「思ったことをポストする」だけで課題管理が成立する状態を作る
- 溜まった課題を分類・可視化し、その人の「やること」と「価値」を見出せるようにする
- 課題に対して AI が調査結果や解決方針をリプライで返し、着手のハードルを下げる

## 対象ユーザー

個人利用（自分の PC で完結。ログイン・同期なし）

- アカウント・他人からのリプライなど複数人向けの機能は、当面保留（Q-013）。1人で使って価値を確かめてから再検討する

## 主要機能

| # | 機能 | 概要 |
| --- | --- | --- |
| F1 | ポスト | Twitter のように短文を気軽に投稿できる |
| F2 | 自動分類・タスク化 | ポストを読み取り、種別（課題 / 思い付き / 調査 など）と属性（「〜の〜をする」形式の対象・行動）を抽出してタスクに起こす |
| F3 | 可視化 | 分類ごとの課題を可視化し、課題の量や傾向から「やること・価値」を見出せるようにする |
| F4 | AI リプライ | 調査結果や簡単な解決方針を AI がリプライとして返す |
| F5 | 関連タスクの派生 | タスクに関連するタスクを紐づけ、新しいタスク（ポスト）として起こす（スレッド的な親子関係） |

## 非機能要件

- 動作環境: Windows デスクトップ（Tauri）
- データ保存: ローカル SQLite
- AI 処理: まず Claude API を使い、後からローカル LLM に差し替えられる設計にする（[ADR-002](../decisions/ADR-002-llm-provider.md)）。AI が使えないときもポストの保存・表示はできること
- プライバシー: ポスト内容を外部 AI に送信する範囲をユーザーが把握できること
