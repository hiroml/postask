# 用語集

仕様書・コード・会話で使う言葉を統一するための一覧です。コード上の命名もこれに合わせます。

| 用語 | コード上の名前 | 説明 |
| --- | --- | --- |
| ポスト | `Post` | ユーザーが投稿する短文。すべての入力の起点 |
| タスク | `Task` | ポストから AI が起こした管理対象。1つのポストから0個以上生まれる |
| 種別 | `TaskKind` | タスクの大分類。例: 課題 (`Issue`)、思い付き (`Idea`)、調査 (`Research`) |
| 属性 | `TaskAttribute` | タスクの中身を構造化したもの。「〜の（対象）〜をする（行動）」の対象・行動など |
| 分類 | `Classification` | ポストを読み取って種別・属性を付ける処理 |
| AI リプライ | `AiReply` | AI がポストやタスクに返す調査結果・解決方針 |
| 関連タスク | `related` / `parent_id` | あるタスクから派生して起こされたタスク。親子で紐づく |
| タイムライン | `Timeline` | ポストと AI リプライを時系列に並べた一覧 |
| ユーザー | `User` | アプリの利用者 |
