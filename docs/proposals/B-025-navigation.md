# ナビゲーター（ページ構成とメニュー）の素案

AI が作ったおすすめの素案です。これをたたき台に相談し、決まったら仕様書にします。
**決めてほしい点は最後の「相談したいこと」にまとめています。**

## 方針

- **X（旧 Twitter）と同じく、左にメニュー、中央にページ**。使い慣れた配置にして、覚えることを減らす。
- メニューに並べるのは「毎日使うページ」だけにし、たまに使うもの（設定・ログアウトなど）は左下の**アカウントメニュー**にまとめる。
- 1人利用の今（Q-013）は、他ユーザーに関わる要素を出さない。将来、複数人に広げるときに足せる形にしておく。

## 作り方（技術）

- **ページの切り替え**: Leptos 公式のルーター（`leptos_router`）を使い、ページごとにパスを割り当てる。**新しい依存クレートなので、追加には承認が必要**。

  | パス | ページ |
  | --- | --- |
  | `/` | ホーム |
  | `/tasks` | 課題 |
  | `/topics`、`/topics/:id` | 話題、話題のプレビュー |
  | `/notifications` | 通知 |
  | `/profile` | プロフィール |
  | `/settings` | 設定 |

- **ウィンドウの大きさ**: 今の既定（800×600）だとメニューとページを並べると狭いので、1100×760 程度に広げる（`tauri.conf.json`）。
- **段階的に作る**:
  1. ナビゲーターとページの切り替え。ホームは今の画面を移し、他は「準備中」の空ページ
  2. 課題ページ（B-003）
  3. プロフィール・設定・通知（B-015, B-024, B-006, B-026）
  4. 話題・検索（B-017, B-018, B-027）

## 相談したいこと

1. **ページの構成**: 上の6ページでよいか。足したい・減らしたい・名前を変えたいページはあるか（例: 「課題」を「ダッシュボード」にする、など）
2. **メニューの位置**: 左のメニュー（X と同じ）でよいか。上のタブ、下のタブなども可能
3. **課題と話題を分けるか**: グラフは「課題」、話題の一覧・検索は「話題」と分ける案にしたが、1ページにまとめる案もある
4. **設定に置くもの**: AI・通知・表示・データのほかに置きたいものはあるか
5. **最初のバッチでどこまで作るか**: 上の「段階的に作る」の 1 だけか、2 まで一緒にやるか
