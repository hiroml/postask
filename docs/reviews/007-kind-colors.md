# 007: 種別の色とチップの見直し — 確認依頼

## 変更概要

種別の色を、配色の検証を通した候補A（課題 `#4a3aa7` 紫紺 / 思い付き `#eda100` 黄 / 調査 `#1baf7a` 緑青 / メモ `#64748b`）に変えました（Q-027）。
チップは「色の点＋濃い文字」にして、どの色でも文字が読めるようにしました。「課題」は赤ではなくなりました。

## 変更ファイル

| 場所 | 内容 |
| --- | --- |
| `src-tauri/src/kind.rs` | 種別の色 |
| `styles.css` | チップの背景・枠・色の点（`::before`）・濃い文字、完了チェックの色 |
| `src/pages/tasks.rs` | 課題ページの種別の表示を同じ見た目に |

## 人に確認してほしいこと

1. **完了チェックの見た目を変えた**: 仕様では「チェックはチップの色で塗る」でしたが、黄・緑青の上に白い ✓ だと読めないため、**薄い塗り＋濃い ✓** にしました。
2. **黄・緑青の点**: 白い背景に対するコントラストは 3:1 未満ですが、点には必ず種別の文字が付くので、色だけに頼る表示にはなっていません。

## 動作確認手順（人向け）

1. `cargo tauri dev` でホームを開く → チップが「色の点＋種別名＋タイトル」になっている。「課題」は紫紺（**AC-1**）
2. タスクを完了にする → チェックが薄い塗り＋濃い ✓ になる（**AC-4**）
3. 「✅ 課題」ページの一覧の種別も同じ見た目（**AC-1**）
