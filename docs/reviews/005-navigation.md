# 005: ナビゲーター — 確認依頼

## 変更概要

左にメニューを置き、ホーム・課題・話題・通知・プロフィール・設定の6ページを切り替えられるようにしました（`leptos_router`）。
中身の無いページは薄い色で表示し、開くと「準備中」と予定を出します。ホームの状態（タイムライン・下書き・裏で届いた結果）はページを移動しても残ります。

## 人に確認してほしいこと

1. **`leptos_router` の不具合を避けた**: 知らないパスでホームへ移る `<Redirect>` が、描画中に URL を書き換えてアプリが止まる（`RuntimeError: unreachable`）ことを確認中に見つけました。描画が終わってから移動する自前の処理（`GoHome`）に置き換えています。実アプリは `/` で起動するので普段は起きませんが、念のためです。
2. **入力中の下書きも残す**: 仕様 FR-6 に合わせ、下書きもページの外に置きました。別のページへ行って戻っても、書きかけの文が残ります。
3. **アカウントメニューの名前**: 当面「自分」と固定表示です（B-015 / B-024 で設定できるようにする予定）。
4. **確認中の出来事（アプリの問題ではありません）**: 「開発版」の印の確認で、ページが止まったように見えたことがありましたが、原因は AI が作った確認用スクリプトの書き間違いでした（計画の作業ログに記録）。

## 動作確認手順（人向け）

1. `cargo tauri dev` を起動し直す（ウィンドウが大きくなる）
2. **AC-1, AC-2**: メニューの各項目をクリック → ページが変わり、強調が移る。話題・通知・プロフィール・設定は薄く、開くと「準備中」
3. **AC-3, AC-4**: ホームで入力欄に文字を書きかけ、いずれかのポストで「AI に聞く」→ すぐ「課題」へ移動 → 10秒ほど待ってホームへ戻る → 書きかけの文と AI のリプライがある
4. **AC-5**: ウィンドウの幅を狭める → メニューがアイコンだけになり、マウスを乗せると名前
5. **AC-6**: 左下の「自分 ⋯」→ プロフィール・設定だけ。Esc や外のクリックで閉じる
6. **AC-7**: Tab キーでメニューを移動し、Enter でページを開ける
