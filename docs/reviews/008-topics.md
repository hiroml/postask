# 008: 話題 — 確認依頼

## 変更概要

「話題」（取り組んでいるテーマ）を作れるようにしました。入力欄で「# 話題として投稿」を選ぶと AI が名前を提案し、確認して作れます。話題ページからも作れます。
普段のポストは、分類と同じ1回の AI 呼び出しで当てはまる話題（最大3つ）を判定し、チップで表示します。話題を作ると直近100件のポストを振り分け直します。
チップの × で外した話題は、AI が付け直しません。話題ページでは、話題ごとのポスト数・未完了のタスク数の確認と、編集・削除ができます。

## 人に確認してほしいこと

1. **DB の更新（版4）**: 開発用 DB は起動時に版4になります。普段使いの DB は、リリース版を起動したときに更新されます（データは消えません）。
2. **名前の提案が長すぎたとき**: 最初の実 API の確認で20文字を超えたため、プロンプトを「12文字前後・括弧の補足なし」にし、それでも超えたら括弧を外してから20文字に切り詰めます。
3. **話題を渡す上限**: 分類のときに AI に渡す話題は、最近使われた順（まだ使われていない話題は新しい順）に50件までです（仕様の NFR-1。話題が多すぎると料金と精度に響くため）。
4. **話題のポスト**: 話題として投稿したポストはタスクに分類せず、「# 話題を作成」の印を付けます。

## 動作確認手順（人向け）

1. `cargo tauri dev` → 入力欄の右の選択を「# 話題として投稿」にし、「x-clone の開発: Tauri と Leptos で作るタスク管理アプリ」と入れて「話題を作る」→ 名前が提案される → 「作成」（**AC-1**）
2. しばらくすると、過去のポストのうち関係するものに「# x-clone開発」のチップが付く（**AC-7**）
3. 「ナビゲーターのページを増やす」とポスト → 同じチップが付く。「今日は眠い」には付かない（**AC-2, AC-3**）
4. チップの × で外す → アプリを再起動しても戻らない（**AC-4**）
5. メニューの「# 話題」→ ポスト数・未完了のタスク数が出る。ここから作る・編集・削除ができ、ここで作ってもタイムラインにポストは増えない（**AC-5, AC-6, AC-9**）
