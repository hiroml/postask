# 006: 課題ページ — 実装計画

## 方針

- `feat/005-navigation` から枝分かれして作る（`/tasks` のページ枠を使う）。
- 集計はすべてバックエンド（`dashboard.rs`、SQL）で行い、単体テストで確かめる。フロントは受け取った数字を SVG で描くだけ。
- グラフの色は dataviz スキルの方針に従い、配色の検証スクリプトを（Node.js が無いため）ヘッドレス Edge で動かして確認する。

## タスク

- [x] **T1: 集計（バックエンド）**（FR-2, FR-4, FR-9, FR-14, FR-16, FR-18 / AC-2, AC-9）

    - 現在時刻を引数で受け取り、日付の境目をテストできるようにする

  - `get_task_dashboard` コマンド
  - 単体テスト: 絞り込み、完了率（0件は None）、日・週の区切りと境目、全期間の開始週、並び順、500件の上限
