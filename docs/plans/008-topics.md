# 008: 話題 — 実装計画

## 方針

- `feat/007-kind-colors` から枝分かれして作る（チップの見た目をそろえるため）。
- 振り分けは、今の分類（1回の AI 呼び出し）の出力に `topic_ids` を足して行う。別の呼び出しを増やさない。
- 話題として投稿したポスト（`posts.kind = 'topic'`）は、タスクへの分類をしない。
- 話題を作ったときの振り分け直し（直近100件）は、裏で1回だけ AI を呼ぶ。
