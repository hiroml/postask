# 007: 種別の色とチップの見直し — 実装計画

## 方針

- 色は `kind.rs` の `color` を替えるだけ（Q-027 候補A）。フロントは `list_kinds` で受け取る仕組みのまま。
- チップは「薄い色の背景（種別の色を白に混ぜる）＋種別の色の点＋濃い文字」にする。ホームのチップと課題ページの一覧の種別表示を同じ見た目にそろえる。
- 文字のコントラストは、薄い背景と濃い文字の組み合わせを検証スクリプト（`contrast`）で確かめる。
